# Agenda · Taller de IA aplicado al cáncer de próstata

Astellas · Pamplona · 7 de octubre de 2026 · 16:30–19:30.

Aplicación HTML para asistentes: agenda, ponentes, buscador, favoritos, biblioteca e información práctica. Diseño adaptable al móvil. Los favoritos se guardan en el navegador del visitante.

Contenido del programa MA-MM-21962. Aplicación de demostración creada para el taller. La biblioteca enlaza las fuentes originales; no reproduce los artículos.

## Uso

Abra `index.html` en un navegador con JavaScript o visite la dirección de GitHub Pages indicada en este repositorio.

El archivo es autocontenido y no requiere dependencias ni compilación. Los enlaces de la biblioteca necesitan conexión a Internet.
